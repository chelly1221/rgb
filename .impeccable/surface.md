# RGB Switch control surface

Mode: Operate. A local Windows RGB utility, Korean UI, code-first as explicitly approved. User requested replacement visual identity: custom titlebar, simpler composition, black/dark gray with pink, vermilion, orange and yellow gradients.

## Direction contract

THESIS: A compact light switch panel. The master commands and four real device rows are the interface; decorative dashboards and marketing sections have no role.

OWN-WORLD: Near-black ground, charcoal surfaces, warm white typography, hairline dividers. A pink → vermilion → orange → yellow spectrum is concentrated in the ON command, tiny power mark, and a thin light strip. OFF is a quiet solid charcoal control. No gradient text or blurred glow.

STORY: Identify connected devices, understand which can be controlled, send an explicit ON/OFF command, read its result. Unknown physical illumination is never presented as measured state.

FIRST VIEWPORT: A 44px draggable custom titlebar with three native window controls. Below, compact page title/status, paired master commands, a one-line support summary, then device rows with aligned ON/OFF controls and expandable diagnostics. Footer carries control help.

FORM: Electrical switch panel, original reference-list position 3; retained as the interaction metaphor under a user-pinned replacement palette. No new random seed: the user specified this visual world. Signature interaction: warm selected ON segment appears only after command success; unknown states leave both options neutral.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Constraints: Exact hardware support remains unchanged; manufacturer diagnostics go behind a labeled detail disclosure. Browser demo is explicitly synthetic and reflects the two implemented/two pending device roles. Windows client default 760 × 760, minimum 520 × 560. No raster artwork required; app icon comes from app-icon.svg.
